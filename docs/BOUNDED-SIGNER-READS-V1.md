# Bounded public signer reads V1

Source foundation. Deployment remains held pending the qualifications below.

The public active-token and completed-artifact lookup methods use the same
opaque process WorkRuntimeV1 and actual pool connection configuration as the
server's HTML writer and sign engine. Missing runtime/configuration returns a
controlled 503 from public token routes. It does not create defaults, work
headroom, a tenant identity, signing permission or READY state.

Before an organization is known, a private fixed global lane acquires actual
shared process Parent/DB and SQL grants. The CASE32 token index query returns
only three UUIDs and one32-byte hash, caps candidates at2 and requires exactly1.
Duplicate hashes, including duplicates in one document or across organizations,
refuse scope. The actual native probe transaction rolls back and its original
client/backend fence must retire before the opaque scope can be borrowed. An
uncertain original remains registered; there is no replacement-on-timeout.
The global control observer is a genuine process owner, distinct from the real
tenant observer; it never creates or charges a made-up tenant account.

One real tenant read session locks the document and caches, then the recipient.
Actual fixed deadline/status scalar preflight preserves early active expiry and
state refusals before the cache/controller/body gate. Header metadata never
outputs, compares or expands JSON. All33 variable-width Document scalars, all6
JSON bodies, recipient data and (for active context) confirmation/controller
and exact minimal Current projection are charged before model SQL. The body
loan uses the existing checked8raw+16wire+32MiB adapter. Missing/outdated cache
is unavailable; requests do not measure an old row. Every complete existing
credential, lawful-basis, controller, source and notice check remains in the
native policy callback. No full history row or unpriced changed_sections array
is loaded for Current; the shared pure validator preserves all twelve checks.

M91 origin/current/variables, M92 blocks/metadata and M93 report wire caches
must be genuine and from the current server version. Minimal Current source
uses the same locked M91 current measurement plus exact M74 current identity
and canonical projection guards; a present materialization report is charged
at the actual M75 validated universal65536-byte upper bound. Those installed,
enabled and validated schema guards are a startup/qualification dependency,
never a caller-provided claim. The document report has no such universal bound.
Fresh HTML creation measures its real default{} report (wire2), or acknowledged
bounded worker output, under the original retained creator work loan.

Successful LookupByToken and LookupCompletedArtifactByToken return a retained
result consumer. All API callers must call RecipientContext.CloseReadV1 after
the last actual use, including response encoding, rendering, storage reads and
mutation completion. Request cancellation is not consumer completion. The
factory registry retains the same actual reader/admission/fence if cleanup is
unknown or a caller drops the result. Explicit closure fences new rechecks and
joins every in-flight borrower of the frozen original body before ending the
original consumer. Rechecks reuse that exact opaque scope, preserve original
issuer, credential/deadlines, source, PDF and notice, and keep fresh locks/loans
through the original policy callback, actual read commit and final deadlines.
Lookup never closes a successful result before returning its retained consumer.

Actual production consumer inventory:14 successful lookupTokenOrError routes
(ai_apps1, dsr1, fields2, sign10) defer closure through handler return; completed
PDF download does likewise. The old handler/engine read-recheck clones have
been replaced by the owned same-scope reader. Five direct-public e2e fixture
files retain test consumers to cleanup, including unexpected-success paths.
The three native synthetic credential suites call the unchanged private policy
helper explicitly; their generated fake SQL does not prove public admission.

Remaining qualification and release gates:

- Root formatting, native/race suites and tagged whole compile against exact
  guarded source; actual owned-PG global probe/reader/public route and consumer,
  cancellation, ambiguity, cache absence, observer and shutdown qualification.
- Existing broad e2e fixtures that construct a bare Engine or old direct SQL
  documents require genuine shared runtime and bounded fresh cache setup;
  no fallback or synthetic authority is introduced to keep them green.
- Actual M93 normal Goose Up/empty Down/reinstall/retained Down and all enabled
  M74/M75 constraints/guards, exact SQLC output, rollback fixture and token plans.
- Populated-estate CASE32 index build/maintenance resource measurement, exact
  default query plans, real statement timeouts, bounded old-row maintenance and
  operator-measured process/tenant vectors and pool-plus-direct SQL cap.
- True last observer/process/controller retirement remains a production gate.
  Successful read/session closure does not credit final observer grants;
  no recursive observer or fabricated final-zero assertion is used.
- Asynchronous audit hook payload/string fanout admission and lifetime remains
  held downstream work. This unit detaches identity UUID pointers and eventID
  before hooks, preventing whole source-model retention through interior pointers;
  it does not claim complete asynchronous payload resource admission.
- LookupByRecipientID/email-action/QES-style context is a separate existing
  initial-admission gap and is preserved. Other mutation/history/collection/PDF
  processing/provider/controller/READY gates are not completed by this unit.

For malformed completed records, the complete final-key TrimSpace policy still
runs after genuine body admission. The scalar stage proves only actual fixed
status and token deadline; it does not fabricate a partial Document or infer a
Unicode legal-value check from a SQL approximation. A genuinely unavailable
size/cache remains distinct from a healthy policy refusal. All final-artifact
identity and original 24-hour token checks remain unchanged on successful reads.
